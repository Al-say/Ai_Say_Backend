## 1. 鉴权规则（代码事实）

来源：
- `src/main/java/com/zhupinzan/speaking/config/SecurityConfig.java`
- `src/main/java/com/zhupinzan/speaking/config/CurrentUserArgumentResolver.java`
- `src/main/java/com/zhupinzan/speaking/filter/JwtAuthenticationFilter.java`

### 1.1 Spring Security 路由规则
- `permitAll`：
  - `OPTIONS /**`
  - `/api/auth/**`
  - `/api/home/daily`
  - `/h2-console/**`
  - `/actuator/health`
  - `/api/v1/evaluate/health`
- 其他所有路径：`authenticated`

### 1.2 `@CurrentUser` 解析规则
- 仅当控制器参数标注 `@CurrentUser CurrentUserInfo` 时触发。
- 解析器要求请求属性 `auth.userId` 为正整数；否则抛 `401 UNAUTHORIZED`（`"请先登录"`）。
- `auth.userId` 由 `JwtAuthenticationFilter` 从 JWT 提取并写入 request attribute。

### 1.3 认证判定说明
- 文档中的“鉴权”分两层：
  - Security 层（`permitAll` / `authenticated`）
  - Handler 层（是否要求 `@CurrentUser`）
- 对于 `/api/auth/me`、`/api/auth/bind-device`：虽在 Security 白名单内，但 Handler 层要求 `@CurrentUser`，无有效 `auth.userId` 时返回 401。

## 5. 异常响应结构（全局）

来源：`GlobalExceptionHandler` + `ApiErrorResponse`

### `ApiErrorResponse`
- `success: boolean`
- `code: ErrorCode`
- `message: String`
- `requestId: String`
- `path: String`
- `timestamp: OffsetDateTime`

说明：
- 控制器抛出 `ResponseStatusException` / `IllegalArgumentException` / 未捕获异常时，统一由全局异常处理器封装为 `ApiErrorResponse`（`/api/eval/*` 中显式返回 `EvalDTO.ErrorResp` 的分支除外）。
