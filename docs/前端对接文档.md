# 前端对接文档

## 基本信息
- 基础地址：`http://localhost:2580`
- 认证方式：`Authorization: Bearer <accessToken>`
- 返回时间格式：ISO-8601（如 `2026-02-05T12:34:56Z`）

## 认证模块 `/api/auth`

说明（代码事实）：
- `/api/auth/**` 在 Security 层放行。
- 但 `GET /api/auth/me`、`POST /api/auth/bind-device` 的 Handler 参数包含 `@CurrentUser`，无有效 `auth.userId` 时会返回 `401`。

### POST `/api/auth/register`
用户名密码注册。

请求体示例：
```json
{
  "username": "testuser",
  "password": "Test123456",
  "email": "test@example.com",
  "displayName": "测试用户"
}
```

响应（200）：
```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "expiresIn": 3600,
  "user": {
    "userId": 1,
    "appleSub": null,
    "email": "test@example.com",
    "emailVerified": null,
    "displayName": "测试用户",
    "deviceId": null
  }
}
```

### POST `/api/auth/login`
用户名密码登录。

请求体示例：
```json
{
  "username": "testuser",
  "password": "Test123456"
}
```

响应（200）：
```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "expiresIn": 3600,
  "user": {
    "userId": 1,
    "appleSub": null,
```

### GET `/api/auth/me`
获取当前用户信息。

响应（200）：
```json
{
  "userId": 1,
  "appleSub": null
}
```

### POST `/api/auth/bind-device`
绑定设备。

请求体示例：
```json
{
  "deviceId": "device-uuid"
}
```

响应（200）：
```json
{
  "status": "success",
  "message": "Device bound successfully"
}
```

## 个人模块 `/api/profile`

### GET `/api/profile`
个人信息。

响应（200）：
```json
{
  "userId": 1,
  "displayName": "张三",
  "avatarUrl": null,
  "phone": null,
  "bio": null,
  "email": "test@example.com",
  "emailVerified": null,
  "deviceId": "device-uuid",
  "lastLoginAt": "2026-02-05T12:34:56Z"
}
```

### PATCH `/api/profile`
更新资料（displayName/avatarUrl/phone/bio）。

请求体示例：
```json
{
  "displayName": "新昵称",
  "avatarUrl": "https://example.com/avatar.png",
  "phone": "123456",
  "bio": "hello"
}
```

响应：同 GET `/api/profile`。

### POST `/api/profile/avatar`
上传头像（表单上传）。

表单字段：`file`

响应：同 GET `/api/profile`。

### GET `/api/profile/stats`
用户统计。

响应（200）：
```json
{
  "deviceId": "device-uuid",
  "streakDays": 7,
  "lastActiveDate": "2026-02-05",
  "totalAttempts": 42,
  "totalDurationMs": 3600000
}
```

### POST `/api/profile/device`
绑定设备（个人模块版本）。

请求体示例：
```json
{
  "deviceId": "device-uuid"
}
```

响应（200）：
```json
{
  "status": "success",
  "message": "Device bound successfully"
}
```

### GET `/api/profile/login-history`
登录历史。

请求参数：`limit`（默认 50，最大 200）

响应（200）：
```json
[
  {
    "id": 101,
    "loginAt": "2026-02-05T12:34:56Z",
    "loginType": "PASSWORD",
    "deviceId": "device-uuid"
  }
]
```

## 成长模块 `/api/growth`

### GET `/api/growth/history`
历史列表（按设备 + persona 过滤）。

请求参数：
- `persona`：`EXAM_PREP` / `DAILY_LIFE` / `CAREER_GROWTH`
- `limit`：默认 50，最大 200
- `from`：可选，ISO-8601

### GET `/api/growth/history/page`
分页历史。

请求参数：
- `persona`
- `page`：从 0 开始
- `size`：默认 50，最大 200
- `from`：可选，ISO-8601

### GET `/api/growth/analysis`
雷达图统计。

请求参数：
- `persona`
- `from`：可选，ISO-8601

### GET `/api/growth/detail/{id}`
评估详情（全量）。

### GET `/api/growth/detail/{id}/lite`
评估详情（轻量，不含 transcript/metrics/feedback）。

### POST `/api/audio/upload`

## 错误处理
- 401：未登录或 Token 无效
- 400：参数错误
- 404：资源不存在
- 500：服务端异常
