# 🚀 快速启动指南

## 第一步：配置环境变量

### macOS/Linux

```bash
# 编辑 ~/.zshrc 或 ~/.bashrc
export DEEPSEEK_API_KEY="sk-你的真实key"
export BAIDU_API_KEY="你的百度key"
export BAIDU_SECRET_KEY="你的百度密钥"

# 应用配置
source ~/.zshrc
```

### IDEA 配置

1. 打开 `Run → Edit Configurations`
2. 选择 Spring Boot 运行配置
3. 在 `Environment Variables` 中添加：
   ```
   DEEPSEEK_API_KEY=sk-xxx;BAIDU_API_KEY=xxx;BAIDU_SECRET_KEY=xxx
   ```

## 第二步：启动应用

```bash
cd /Users/alsay_mac/Synchronization/Github_File/Ai_Say_Backend
mvn clean spring-boot:run
```

## 第三步：测试接口

```bash
# 1. 健康检查
curl http://localhost:2580/api/v1/evaluate/health

# 2. 提交任务
curl -X POST http://localhost:2580/api/v1/evaluate \
  -H "Content-Type: application/json" \
  -d '{
    "persona": "EXAM_PREP",
    "scene": "test",
    "transcript": "I have been studying English for five years.",
    "async": true
  }' | jq

# 3. 查询结果（替换 {taskId}）
curl http://localhost:2580/api/v1/evaluate/{taskId} | jq
```

可选：获取登录历史（需要先登录拿到 accessToken）
```bash
curl http://localhost:2580/api/profile/login-history?limit=50 \
  -H "Authorization: Bearer {accessToken}" | jq
```
