## ⚠️ 常见问题与解决方案

### 端口占用错误 (Port 2580 already in use)

**问题现象**：
```
Web server failed to start. Port 2580 was already in use.
```

**问题根因**：
之前的Spring Boot进程没有完全终止，端口被残留进程占用。

**解决方案**：

**方案一：清理占用端口的进程（推荐）**
```bash
# 1. 查看占用端口的进程
lsof -i :2580

# 2. 杀掉进程（将 <PID> 替换为实际进程ID）
kill -9 <PID>

# 3. 重新启动应用
mvn spring-boot:run
```

**方案二：使用不同端口**
```bash
# 临时使用8080端口
mvn spring-boot:run -Dspring-boot.run.arguments="--server.port=8080"
```

**方案三：修改配置文件**
在 `application.yml` 中添加：
```yaml
server:
  port: 8080
```

**预防措施**：
- 停止应用时使用 `Ctrl+C` 而不是直接关闭终端
- 启动前先检查端口是否被占用：`lsof -i :2580`
- 如遇跨域问题，已配置CORS支持前端访问

## 第四步：测试接口

```bash
# 1. 健康检查 (Spring Boot Actuator)
curl http://localhost:2580/actuator/health

# 2. 提交评估任务 (需要JWT认证)
curl -X POST http://localhost:2580/api/v1/evaluate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -d '{
    "persona": "EXAM_PREP",
    "scene": "Describe your favorite food",
    "transcript": "I really enjoy eating pizza because it has delicious cheese and various toppings."
  }' | jq

# 3. 查询任务状态 (替换 {taskId})
curl -X GET http://localhost:2580/api/v1/evaluate/{taskId} \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" | jq

# 4. 查询历史记录
curl -X GET http://localhost:2580/api/v1/evaluate/history \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" | jq
```

可选：获取登录历史（需要先登录拿到 accessToken）
```bash
curl http://localhost:2580/api/profile/login-history?limit=50 \
  -H "Authorization: Bearer {accessToken}" | jq
```
