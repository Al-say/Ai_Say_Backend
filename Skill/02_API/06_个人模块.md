# 个人模块

## 背景与目的
提供个人中心功能。

## 范围与不包含
- 包含：统计、设备绑定
- 不包含：设置修改

## 核心概念与名词表
- ProfileStats：统计数据
- Device：设备信息

## 关键流程
获取用户统计。

## 关键接口或关键文件位置
- ProfileController.java

## 常见失败模式与排障
- 未绑定设备：提示绑定

## API端点

### GET /api/profile
个人主页信息。

**响应示例：**
```json
{
  "user": {...},
  "stats": {...}
}
```

### GET /api/profile/stats
用户统计数据。

**响应：** 练习统计

### POST /api/profile/device
绑定设备。
