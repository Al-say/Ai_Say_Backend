# 评估模块

## 背景与目的
提供口语评估功能。

## 范围与不包含
- 包含：文本和音频评估
- 不包含：其他评估类型

## 核心概念与名词表
- EvalDTO：评估请求
- AssessmentResult：评估结果

## 关键流程
上传内容 -> AI评测 -> 返回结果。

## 关键接口或关键文件位置
- EvalController.java

## 常见失败模式与排障
- 音频格式错误：检查文件类型

## API端点

### POST /api/eval/text
文本评估。

**请求体：**
```json
{
  "text": "评估文本",
  "persona": "EXAM_PREP"
}
```

**响应示例：**
```json
{
  "score": 85,
  "feedback": "反馈内容"
}
```

### POST /api/eval/audio
音频评估（简化）。

**请求：** Multipart file

**响应：** 类似文本评估

### POST /api/eval/audio/full
完整音频评估。

**请求：** Multipart file + 参数

**响应：** 详细评估结果
