# 成长模块

## 背景与目的
提供用户成长数据。

## 范围与不包含
- 包含：历史记录、分析
- 不包含：数据修改

## 核心概念与名词表
- AssessmentRecord：评估记录
- RadarStats：雷达图统计

## 关键流程
查询用户历史数据。

## 关键接口或关键文件位置
- GrowthController.java

## 常见失败模式与排障
- 无数据：用户未练习

## API端点

### GET /api/growth/history
评估历史列表。

**请求参数：**
- page, size (分页)

**响应示例：**
```json
{
  "records": [...],
  "total": 100
}
```

### GET /api/growth/analysis
能力分析数据。

**响应：** 雷达图数据

### GET /api/growth/detail/{id}
单次评估详情。
