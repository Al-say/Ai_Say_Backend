# 首页模块

## 背景与目的
提供用户首页功能，包括每日挑战。

## 范围与不包含
- 包含：每日挑战获取
- 不包含：其他首页功能

## 核心概念与名词表
- DailyTopic：每日挑战题目
- Persona：用户画像

## 关键流程
根据用户画像推荐每日挑战。

## 关键接口或关键文件位置
- HomeController.java

## 常见失败模式与排障
- 无挑战数据：检查数据库

## API端点

### GET /api/home/daily
获取每日挑战。

**请求参数：**
- persona (query, optional): 用户画像，默认EXAM_PREP

**响应示例：**
```json
{
  "topicDate": "2023-01-01",
  "persona": "EXAM_PREP",
  "title": "挑战标题",
  "prompt": "挑战内容"
}
```

**错误示例：**
```json
{
  "error": "INTERNAL_ERROR",
  "message": "服务异常"
}
```
