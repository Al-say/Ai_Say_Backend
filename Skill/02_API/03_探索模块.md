# 探索模块

## 背景与目的
提供场景探索功能。

## 范围与不包含
- 包含：场景列表获取
- 不包含：场景创建

## 核心概念与名词表
- Scene：练习场景
- Persona：用户画像

## 关键流程
根据画像推荐场景。

## 关键接口或关键文件位置
- ExploreController.java

## 常见失败模式与排障
- 无场景：检查数据库

## API端点

### GET /api/explore/scenes
获取场景列表。

**请求参数：**
- persona (query, optional): 用户画像，默认EXAM_PREP
- category (query, optional): 分类

**响应示例：**
```json
[
  {
    "id": 1,
    "code": "IELTS_1",
    "title": "场景标题",
    "description": "描述",
    "category": "IELTS",
    "targetPersona": "EXAM_PREP",
    "initialPrompt": "初始提示",
    "imageUrl": "图片URL",
    "recommendedPrompts": ["提示1", "提示2"]
  }
]
```

**错误示例：**
```json
{
  "error": "BAD_REQUEST",
  "message": "参数无效"
}
```
