# 测试策略

## 背景与目的
定义项目的测试策略，确保代码质量和功能正确性。

## 范围与不包含
- 包含：单元测试、集成测试、API测试
- 不包含：性能测试、端到端UI测试

## 核心概念与名词表
- 单元测试：测试单个方法或类
- 集成测试：测试组件间交互
- API测试：测试REST端点

## 关键流程
1. 编写单元测试覆盖核心逻辑
2. 运行集成测试验证服务交互
3. 执行API测试确保端点功能
4. 代码审查前运行测试套件

## 关键接口或关键文件位置
- 测试目录：`src/test/java/`
- 测试框架：JUnit 5, Spring Boot Test
- 模拟对象：Mockito

## 常见失败模式与排障
- 测试不稳定：检查依赖注入，清理测试数据
- 覆盖率低：添加更多边界条件测试
- 异步测试失败：使用Awaitility等待异步操作
