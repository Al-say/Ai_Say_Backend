# 总体架构

## 背景与目的
AI 驱动的英语口语练习与评估平台后端，基于 Spring Boot 3.2.0 + Java 21。

## 技术栈

| 层次 | 技术 |
|------|------|
| 框架 | Spring Boot 3.2.0, Spring Security 6.x |
| 语言 | Java 21 |
| 数据库 | PostgreSQL（生产）/ H2（测试） |
| AI 服务 | DeepSeek API（评分）、百度 ASR（语音转文字） |
| 音频处理 | FFmpeg（转码）、FFprobe（元数据） |
| 文件存储 | 本地文件系统 `./uploads`（LocalStorageService） |
| 认证 | JWT（用户名/邮箱 + 密码） |
| 弹性容错 | Resilience4j（重试 + 熔断） |
| 异步处理 | Spring `@Async` + 自定义线程池 |
| 构建 | Maven |

## 分层架构

```
[客户端]
    ↓ HTTP + JWT Bearer Token
[Filter 层] JwtAuthenticationFilter → RequestIdFilter → RateLimitingInterceptor
    ↓
[Controller 层]
  AuthController       → 注册/登录/JWT 签发
  HomeController       → 每日挑战题目
  ExploreController    → 场景探索
  EvalController       → 文本评估（同步）
  EvaluationController → 音频评估（异步 TaskID 模式）
  AudioController      → 音频上传 + 转码
  GrowthController     → 成长数据 / 雷达图
  ProfileController    → 用户信息 / 登录历史
    ↓
[Service 层]
  AuthUserService         → 注册 / 登录 / 设备绑定
  AudioService            → 音频评估业务编排
  AsyncEvaluationService  → 异步任务管理（TaskID 轮询）
  EvalOrchestratorService → 评估链路编排
  DeepSeekEvalService     → DeepSeek AI 调用
  BaiduAsrService         → 百度语音识别
  DailyChallengeService   → 每日题目（AI 生成 + DB 缓存）
  SceneService            → 场景数据
  GrowthService           → 成长分析
  audio/AudioTranscodeService → FFmpeg 转码
  audio/AudioMetaService     → FFprobe 元数据
  storage/LocalStorageService → 本地文件存储（./uploads）
    ↓
[Repository 层]
  UserAccountRepository / AssessmentRecordRepository
  EvaluationTaskRepository / DailyTopicRepository
  DeviceRepository / UserProgressRepository
  SceneRepository / LoginHistoryRepository
    ↓
[数据库] PostgreSQL
```

## 核心数据流程

### 音频评估流程（异步）
```
客户端上传音频
  → AudioController 接收 + 转码（FFmpeg WAV 16k Mono）
  → 存储至 ./uploads（LocalStorageService）
  → BaiduAsrService 语音转文字
  → AsyncEvaluationService 创建 EvaluationTask（TaskID）
  → 后台 @Async DeepSeekEvalService 调用 AI 评分
  → 客户端轮询 GET /api/v1/evaluate/{taskId}
  → 返回 6 维评分 + 反馈文本
```

### 认证流程
```
POST /api/auth/register → AuthUserService.register() → UserAccount 入库 → JWT
POST /api/auth/login    → AuthUserService.login()    → 验证密码 → JWT
所有请求 → JwtAuthenticationFilter 校验 Bearer Token
```

## 关键配置项

| 配置键 | 说明 |
|--------|------|
| `deepseek.api.key` | DeepSeek AI API 密钥 |
| `baidu.app-id/api-key/secret-key` | 百度 ASR 凭证 |
| `jwt.secret` | JWT 签名密钥（≥32字符） |
| `ffmpeg.path` / `ffprobe.path` | 本地 FFmpeg 路径 |
| `storage.local-path` | 文件存储根目录（默认 `./uploads`） |
| `scene.prompts.exam-prep/career-growth` | 场景提示词 |

## 常见失败模式与排障
- 循环依赖：检查 Service 层注入
- AI 评估超时：检查 Resilience4j 熔断配置和 DeepSeek API 网络
- 音频转码失败：确认 `ffmpeg.path` 和 `ffprobe.path` 指向正确路径
- 文件存储失败：检查 `./uploads` 目录写权限
- 登录历史不生效：检查是否写入 `login_history` 表
