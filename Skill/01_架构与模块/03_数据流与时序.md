# 数据流与时序

## 背景与目的
描述关键业务链路的数据流与时序。

## 范围与不包含
- 包含：认证登录、登录历史查询
- 不包含：评估异步链路细节

## 关键流程

### 登录（用户名/Apple）
客户端请求 -> AuthController -> AuthUserService/AppleSignInService  
-> UserAccountRepository (更新 last_login_at)  
-> LoginHistoryService -> LoginHistoryRepository (写 login_history)

### 查询登录历史
客户端请求 -> ProfileController  
-> AuthUserService (校验用户)  
-> LoginHistoryService -> LoginHistoryRepository (按 user_id 倒序查询)

## 常见失败模式与排障
- 登录历史为空：确认 `login_history` 表存在且写入未失败
- 登录成功但历史缺失：检查日志 `login history save failed`
