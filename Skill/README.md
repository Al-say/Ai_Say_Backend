# Skill 知识库

## 项目概览
- 项目目标：AI 口语练习与评估平台
- 核心流程：探索 -> 评估 -> 成长 -> 画像/推荐
- 技术栈：后端(Spring Boot/Java 21) + iOS(Swift) + AI评测
