# 项目概览

## 背景与目的
本项目是一个AI驱动的口语练习与评估平台，帮助用户通过音频录制和AI评测提升口语能力。用户可以选择不同场景进行练习，系统使用DeepSeek AI进行智能评测，提供详细反馈和成长分析。

## 范围与不包含
- 包含：用户注册（用户名/邮箱+密码）、音频上传、AI评测（DeepSeek + Baidu ASR）、成长追踪、个性化推荐、设备管理
- 不包含：前端界面、Apple Sign-In、S3/MinIO 对象存储、实时语音通话

## 核心概念与名词表
- 用户画像（UserPersona）：基于评估结果的用户能力模型，包括EXAM_PREP（备考党）和CAREER_GROWTH（职场人）
- 评估模式（AssessmentMode）：不同类型的口语练习场景，如基础练习、随机模式
- 成长模块：基于历史数据的进步分析，包括雷达图统计和连续练习天数
- 设备绑定：通过device_id实现多设备数据同步
- TraceId：请求追踪ID，用于日志关联

## 核心概念与名词表
- 用户画像：EXAM_PREP（备考党）、CAREER_GROWTH（职场人）
- 评估模式：基础练习、随机模式
- 成长模块：历史记录、能力分析、进度追踪

## 关键流程
1. 用户使用用户名/邮箱 + 密码注册/登录，系统签发 JWT Token
2. 用户绑定设备ID，确保数据隔离和多设备同步
3. 用户选择练习场景（Scene），获取每日挑战或探索推荐
4. 用户录制音频，上传后系统转码为 WAV 16k Mono PCM，保存至本地 `./uploads`
5. 系统调用 Baidu ASR 进行语音识别，获取文本转录
6. 使用 DeepSeek AI 对文本进行智能评测，生成分数和反馈（异步任务，TaskID 轮询）
7. 存储评估记录，更新用户进度和画像
8. 用户查看成长数据，包括历史记录和雷达图分析

## 关键接口或关键文件位置
- 主入口：`SpeakingApplication.java`
- 控制器：`controller/`（AuthController, HomeController, ExploreController, EvalController, EvaluationController, GrowthController, ProfileController, AudioController）
- 服务层：`service/`（AuthUserService, DeepSeekEvalService, BaiduAsrService, AudioService, DailyChallengeService, GrowthService, SceneService）
- 音频处理：`service/audio/`（AudioTranscodeService, AudioMetaService）
- 文件存储：`service/storage/LocalStorageService`（本地 `./uploads`）
- 异步评估：`service/AsyncEvaluationService`、`service/EvalOrchestratorService`
- 数据层：`repository/`（UserAccountRepository, AssessmentRecordRepository等）
- 实体：`model/entity/`（UserAccount, AssessmentRecord, Device, UserProgress, EvaluationTask等）

## 常见失败模式与排障
- 数据库连接失败：检查 PostgreSQL 配置和环境变量 `DB_PASSWORD`
- AI 服务超时：检查网络连接和 Resilience4j 熔断配置
- 音频格式不支持：确保上传文件为常见音频格式，系统会自动转码
- 文件存储失败：检查 `./uploads` 目录权限
- 设备未绑定：调用 `/api/auth/bind-device` 绑定设备ID
