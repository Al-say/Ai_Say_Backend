# 本地启动

## 背景与目的
指导开发者在本地环境启动项目进行开发和测试，确保所有依赖服务正常运行。

## 范围与不包含
- 包含：依赖安装、环境配置、启动步骤、健康检查
- 不包含：生产部署、Docker配置

## 核心概念与名词表
- JDK：Java Development Kit，版本21
- Maven：项目构建工具
- PostgreSQL：主数据库
- DeepSeek：AI评测服务
- Baidu ASR：语音识别服务
- AWS S3：文件存储服务

## 关键流程
1. 安装JDK 21和Maven
2. 启动PostgreSQL数据库，创建speaking_db数据库
3. 设置环境变量（DB_PASSWORD, DEEPSEEK_API_KEY, BAIDU_APP_ID等）
4. 运行`mvn clean compile`编译项目
5. 运行`mvn spring-boot:run`启动应用
6. 访问http://localhost:8082进行健康检查

## 关键接口或关键文件位置
- 配置文件：`src/main/resources/application.properties`
- 启动类：`SpeakingApplication.java`
- 数据库脚本：`schema.sql`

## 常见失败模式与排障
- 端口占用：检查8082端口是否被占用，可修改`server.port`
- 数据库连接失败：确保PostgreSQL运行，用户名alsay_mac正确，密码通过DB_PASSWORD设置
- AI服务失败：检查DEEPSEEK_API_KEY和BAIDU_API_KEY等环境变量
- 编译失败：运行`mvn clean`清除缓存后重新编译
- 音频处理失败：确保ffmpeg已安装（用于音频转码）
