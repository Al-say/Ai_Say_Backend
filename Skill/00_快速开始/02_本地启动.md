# 本地启动

## 背景与目的
指导开发者在本地环境启动项目进行开发和测试，确保所有依赖服务正常运行。

## 范围与不包含
- 包含：依赖安装、环境配置、启动步骤、健康检查
- 不包含：生产部署、Docker配置

## 核心概念与名词表
- JDK：Java Development Kit，版本21
- Maven：项目构建工具
- PostgreSQL：主数据库
- DeepSeek：AI评测服务
- Baidu ASR：语音识别服务
- FFmpeg：音频转码

## 关键流程
1. 安装 JDK 21 和 Maven
2. 安装 FFmpeg（`brew install ffmpeg`）
3. 启动 PostgreSQL，创建 `speaking_db` 数据库
4. 设置环境变量（`DEEPSEEK_API_KEY`, `BAIDU_APP_ID`, `BAIDU_API_KEY`, `BAIDU_SECRET_KEY`）
5. 运行 `mvn clean compile` 编译项目
6. 运行 `mvn spring-boot:run` 启动应用
7. 访问 `http://localhost:2580/actuator/health` 进行健康检查

## Docker 启动（推荐）
```bash
cp .env.example .env  # 填入真实密钥
docker-compose up -d  # 启动 PostgreSQL + 应用
```

## 关键接口或关键文件位置
- 配置文件：`src/main/resources/application.properties`
- 启动类：`SpeakingApplication.java`
- 数据库脚本：`schema.sql`

## 常见失败模式与排障
- 端口占用：检查 2580 端口是否被占用，可修改 `server.port`
- 数据库连接失败：确保 PostgreSQL 运行，密码通过环境变量正确设置
- AI 服务失败：检查 `DEEPSEEK_API_KEY` 和 `BAIDU_API_KEY` 等环境变量
- 音频处理失败：确保 `ffmpeg` 已安装，`ffmpeg.path` 和 `ffprobe.path` 配置正确
- 编译失败：运行 `mvn clean` 清除缓存后重新编译
